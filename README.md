# 🌙 LUNA NAV – Lunar Landing Site Navigator

### NASA Space Apps Challenge 2026

**Project Goal**

LUNA NAV is an interactive platform designed to help users compare potential lunar landing sites and dates by visualizing solar illumination, Earth visibility, and mission conditions.

### Core Features
- Interactive lunar landing site explorer
- Sun azimuth and elevation visualization
- Earth visibility analysis
- Landing date comparison
- Mission feasibility assessment
- 3D lunar terrain visualization
- AI-powered mission explanations

### Technology Stack
- Frontend: React + TypeScript
- Backend: Python + FastAPI
- Scientific data: NASA JPL Horizons, NAIF SPICE and lunar datasets
- Version control: GitHub
