MODULE 07 / EXPLAINABLE DECISION SUPPORT

AI Recommendation

A transparent weighted scoring engine that evaluates supplied inputs. It refuses to rank sites when critical safety evidence is missing.

Scoring configuration

CLIENT-SIDE MODEL

Weights are configurable. The engine normalizes the weights and requires a complete set of inputs for each site.

A weighted score cannot override a critical safety failure. Each site must pass the maximum-slope and hazard constraints before it can be recommended.
